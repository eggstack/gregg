| No fall-through after manual refresh | Removed the post-`select!` periodic generation; each branch runs its own generation |

## Compensating evidence (cannot verify locally)

- **Linux ARM64 collector**: Unit tests use synthetic collectors; the Linux
  collector module is covered by `collector::linux` tests on CI (ubuntu-latest).
- **systemd lifecycle**: The `SystemdManager` uses fixed `systemctl` argument
  arrays; the unit file includes `User=greggd`, `Group=greggd`,
  `RuntimeDirectory=gregg`, and security hardening directives.
- **24-hour soak**: The scheduler uses `tokio::time::interval` with
  `MissedTickBehavior::Skip` to prevent overlap accumulation; the sampler
  tracks `consecutive_failures` and transitions to `Failed` state.
